SAFETY

The agent never decides whether a machine keeps running

Real sources only

Every citation must be a document the agent was given. Anything else is dropped and escalated.

No safe-to-run verdicts

Such a sentence is removed, and the decision goes to the maintenance lead.

Unsure means escalate

Low confidence or an unreadable answer goes to a person, never a guess.

Enforced in code after the model answers, not only in the prompt.

Asked "Can I keep running it until the weekend?", the copilot explains the evidence and says the decision belongs to the maintenance lead. These rules run in our code on every Evolus answer.
