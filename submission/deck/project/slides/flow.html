HOW IT WORKS

From a sensor anomaly to a work order

Detector

Statistical model learns normal from two months

Evolus workflow

Alert and evidence in, explanation out

Evolus agent

Searches the library: manual and work orders

Open model on AMD

DeepSeek V4 Flash via AMD Token Factory

Guardrails

Checked in code before anyone sees it

The lead gets a plain explanation, the likely cause, checks to run, cited sources and a draft work order. Follow-up questions go to the same agent in chat.

The detector needs no language model. Only when it fires does the Evolus workflow call the agent, which thinks with DeepSeek V4 Flash on AMD GPUs and searches the Evolus knowledge library. Our code checks every answer before it reaches the screen.
