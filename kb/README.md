# Knowledge base (SYNTHETIC)

Everything in this folder was **written for this project** to demo the copilot. It is not a real
manufacturer's manual and these are not real work orders. The equipment is modelled on the
oil-injected screw compressor air production unit (APU) described for the public MetroPT-3 dataset,
and the sensor tags match that dataset's columns so detector output maps onto manual sections.

- `manual.md` — operating and troubleshooting manual for the APU.
- `work_orders/` — past maintenance work orders, one per file.

These files are uploaded to an Evolus knowledge library; the agent cites them by file name.
